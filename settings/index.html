Einstellungen

Die ersten Einstellungen für Radon Search.

Darstellung

Aktuell ist das dunkle Design mit gelben Akzenten aktiv. Weitere Optionen können ergänzt werden, sobald die Suchfunktionen ausgebaut werden.

Datenschutz

Die Oberfläche verwendet keine Analyse- oder Tracking-Skripte. Wenn du eine Suche abschickst, wird der Suchbegriff als URL-Parameter an die Ergebnisseite übergeben.
